# CloudVault – Software Design Document

This folder contains the Software Design Document (SDD) for **CloudVault**, a multi-user cloud file storage and sharing system.

   Project overview, main objectives, scope boundaries, and user roles.

3. [Non-Functional Requirements](03-non-functional-requirements.md)

4. [Technology Stack & Architecture](04-technology-and-architecture.md)
